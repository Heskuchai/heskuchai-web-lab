# OPORA

Авторський демонстраційний проєкт Heskuchai. Не реальна будівельна компанія.

- Демо: https://heskuchai.github.io/heskuchai-web-lab/opora/
- Плагін: `wordpress/opora-studio/` у корені репозиторію.
- Збірка з кореня: `python build.py`.
- Перевірки: `node --test tests/*.test.cjs`.

Графіка створена програмно у SVG. Ціни та терміни демонстраційні. Готові ZIP-файли збираються в ігноровану папку `build/`.
