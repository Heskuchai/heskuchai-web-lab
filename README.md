# Heskuchai - WordPress portfolio projects

Три авторські демонстраційні проєкти: **BRUTAL Barber**, **Stockroom** та **OPORA**. Це самостійно реалізовані кейси для портфоліо, не замовлення реального бізнесу.
Публікація GitHub Pages: [портфоліо](https://heskuchai.github.io/heskuchai-web-lab/), [BRUTAL](https://heskuchai.github.io/heskuchai-web-lab/barber/), [Stockroom](https://heskuchai.github.io/heskuchai-web-lab/stockroom/), [OPORA](https://heskuchai.github.io/heskuchai-web-lab/opora/).

## Проєкти

### BRUTAL Barber

Адаптивний лендинг вигаданого барбершопа. Послуги, прайс, атмосферна галерея, FAQ, мобільне меню та форма запису. WordPress-плагін із шорткодом `[brutal_barber]`, REST API й окремою таблицею заявок. Унікальний часовий слот у базі захищає від повторного бронювання. Перегляд заявок доступний адміністратору: **BRUTAL · записи**.

Один майстер, слоти по годині 10:00–18:00, понеділок–субота, від завтра на 30 днів, часовий пояс Europe/Kyiv. Телефон - формат +380XXXXXXXXX. SMS, email, Telegram та платежі не підключені. Скасування заявок, кілька майстрів і виробничий антиспам не реалізовані; є базове обмеження частоти за IP. Не використовуйте публічний демопроєкт для реальних персональних даних.

### Stockroom

Каталог товарів: додавання, редагування, архівування зі скасуванням останньої дії, пошук, категорії, статус залишків, сортування та показники вартості запасів. Імпорт/експорт CSV; ціни в цілих копійках. CSV-імпорт валідується повністю; у WordPress застосовується транзакція. Формули в CSV-експорті нейтралізуються початковим апострофом.

WordPress-плагін: `[heskuchai_stockroom]`, панель **Stockroom**, REST API з `manage_options` та WordPress REST nonce. Дані в окремій таблиці InnoDB. Ліміт імпорту - 500 рядків і 1 МБ на клієнті. Артикул унікальний, включаючи архів. Поточний інтерфейс завантажує весь каталог; для великих складів потрібна серверна пагінація. Одночасне редагування товару двома адміністраторами використовує останній запис; обліку рухів і повного інтерфейсу архіву ще немає.

### OPORA

Інтерактивний лендинг будівельної студії. Три різні SVG-будинки, довгий червоний кран із керуванням гаком, зміна вантажу, майстерня з шарами конструкції, плани, день/ніч та калькулятор матеріалів. Плавна прокрутка на комп'ютері, звичайна сенсорна прокрутка та підтримка `prefers-reduced-motion`. Ціни демонстраційні, реальних заявок немає.

WordPress-плагін: `[opora_studio]`. Встановлення: `build/opora-studio-wordpress.zip`. Шаблон: `wordpress/opora-studio/page.html`, стилі й поведінка: `assets/`, SVG-моделі: `projects/opora/models.py`. Після змін запустіть `python build.py`. Дані калькулятора зберігаються у браузері.

## GitHub Pages і WordPress

`docs/` - публічні статичні демонстрації. BRUTAL зберігає лише дату/час/послугу в localStorage, без імені та телефону. Stockroom зберігає демотовари в localStorage. Дані окремі для кожного браузера, не синхронізуються, можуть бути очищені браузером. Це не публічний WordPress-сервер.

`wordpress/` - вихідний код повноцінних плагінів для WordPress/PHP/MySQL. У цій версії дані зберігаються сервером. Не завантажуйте WordPress, бази даних, wp-config.php чи облікові дані в GitHub.

## Встановлення

1. Запустіть `python build.py`.
2. Завантажте `build/brutal-barber.zip` і `build/stockroom.zip` у **Плагіни → Додати новий → Завантажити плагін** та активуйте.
3. Створіть сторінки з відповідними шорткодами. Плагіни надають власний шаблон сторінки на весь екран.
4. Для Stockroom увійдіть як адміністратор. Натисніть «Додати демотовари», щоб завантажити вигаданий каталог.

Оновлена тема портфоліо - `wordpress/cocoa-portfolio/`. HTML-портфоліо експортується командою `python export_portfolio.py`; після змін у темі виконайте її повторно. `prepare_portfolio.py --source PATH` потрібен лише для початкового імпорту теми у порожню папку. Для публікації всієї збірки використовується `docs/` у гілці `main`. Публічні статичні копії самі по собі не синхронізуються з адмінкою локального WordPress.

Для запуску статичних демо: `python -m http.server 8766 --directory docs` та відкрийте `/barber/` або `/stockroom/`.

## Перевірки

`node --test tests/stockroom.test.cjs` - валідація та CSV. PHP перевіряється `php -l`. Результати інтеграційних та браузерних перевірок зберігаються в `CHECKS.md`.

## Редагування портфоліо

Описи, порядок, скриншоти та посилання п’яти робіт зібрані у `portfolio/projects.json`. Структура особистої сторінки - `portfolio/front-page.template.php`, оформлення - `wordpress/cocoa-portfolio/style.css`. Після редагування виконайте `python export_portfolio.py`: команда збирає PHP-шаблон теми та статичну сторінку в `docs/`. Згенерований `front-page.php` окремо не редагуйте. Ім’я, опис та Telegram у локальному WordPress змінюються в налаштуваннях теми; статична публікація потребує нового експорту.

Шрифт Onest збережений локально, без запитів до Google Fonts. Ліцензія SIL Open Font License міститься в `wordpress/cocoa-portfolio/assets/fonts/OFL.txt`.

## Stockroom: оновлений інтерфейс

Версія 1.1.0: світлий журнал із синіми акцентами, таблиця з артикулами та мінімальними залишками, швидкі фільтри, скидання пошуку й довідка CSV. Бокову панель із вигаданою студією прибрано. Дані та API збережено: ключ localStorage `heskuchai-stockroom-v1`, таблиця MySQL та права адміністратора не змінювалися. Нові демокаталоги використовують прості назви товарів; наявні записи не перейменовуються.

Шрифт Onest постачається локально за SIL OFL, ліцензія - `wordpress/stockroom/assets/fonts/OFL.txt`.
